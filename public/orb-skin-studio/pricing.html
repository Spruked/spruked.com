What's included with each orb purchase? +
Every orb includes full access to all customization features: shapes, colors, animations, custom images, avatars, CSS animations, and export capabilities. No feature restrictions based on pricing.
Can I use orbs I create commercially? +
Yes! All orb purchases include commercial usage rights. You can use your created orbs in games, apps, websites, or any commercial project without additional licensing fees.
What's the difference between bulk packs and Pro subscription? +
Bulk packs give you a set number of orbs to create whenever you want. Pro subscription ($14.99/month) gives you unlimited orb creation plus premium features like API access and priority support.
Do bulk purchases expire? +
No expiration! Once you purchase a bulk pack, you can create your orbs at your own pace. Your account will track how many orbs you have remaining to create.
